# dbt_berlin – a small, real dbt project (synthetic data)

Teaching project: raw → staging → marts with dbt-core + dbt-duckdb on synthetic Berlin property-maintenance data.
Read **WALKTHROUGH.md** first.

Quick start:
```bash
python3 -m venv .venv && .venv/bin/pip install dbt-core dbt-duckdb matplotlib
./run_all.sh
```
